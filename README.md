# PC Auto Builder

사용자의 예산, 사용 목적, 본체 규격과 고정 부품을 기준으로
호환되는 컴퓨터 부품 조합을 추천하는 웹사이트입니다.

## 주요 기능

- 예산에 맞는 컴퓨터 부품 추천
- CPU와 메인보드 소켓 호환성 검사
- RAM 규격 호환성 검사
- 그래픽카드와 케이스 크기 검사
- 파워 용량 검사
- 부품 가격 정보 표시

## 프로젝트 구조

- `frontend`: 사용자 화면
- `backend`: 추천 및 호환성 검사 서버
- `data`: 부품 초기 데이터
- `docs`: 프로젝트 설계 문서

## 개발 상태

기본 프로젝트 구조를 구성하는 중입니다.
